# Architecture decisions

The files in this directory are architecture decision records (ADRs). They explain constraints that are easy to miss when reading an individual package.

New users should start with [Getting started](../getting-started.md) and [Core concepts](../core-concepts.md). Read the ADRs when changing the engine, live acquisition, pack protocol or trust boundaries.
