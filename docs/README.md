## Documentation conventions

Guides should show a working path through a task. Reference pages describe behavior precisely and avoid tutorial detours. Architecture decisions record why a design constraint exists; they are not intended to be the first page a new user reads.

Examples in the documentation should use commands and files that exist in the repository whenever possible.
